Skill para Claude Code

Um agente.
Um repositório.

O /repo trava cada sessão do Claude Code em um único repositório do GitHub. Vários agentes podem rodar em paralelo sem que um mexa no projeto do outro, e suas pastas locais continuam em dia com o GitHub.

claude — ~/repos
$ curl -fsSL https://lucasnevescardoso.github.io/claude-skill-repo/install.sh | bash

Também funciona no Git Bash e no WSL. Instala em ~/.claude/skills/repo.

PS> irm https://lucasnevescardoso.github.io/claude-skill-repo/install.ps1 | iex

Rode no PowerShell. Instala em %USERPROFILE%\.claude\skills\repo.

/plugin marketplace add LucasNevesCardoso/claude-skill-repo
/plugin install repo@repo-skill

Digite dentro do Claude Code. Como plugin, a skill recebe atualizações.

Por que travar a sessão?

Com vários agentes abertos, é fácil um deles ler, editar ou rodar comandos no projeto errado. O /repo põe uma cerca em volta de cada sessão.

lock / unlock

Uma cerca por sessão

Depois do lock, o agente só lê, edita e executa dentro daquele repositório. Para sair, ele pergunta antes.

review

Pastas sempre em dia

Compara cada pasta com o GitHub: atrasada, divergente, renomeada, com alterações não salvas ou ainda não clonada.

TaskManagement

Atividade do time

Levanta commits, PRs, code reviews e issues por pessoa, no período que você escolher. Só leitura, só números.

Comandos

Digite /repo sem nada para ver esta lista dentro do Claude Code.

/repo create NOMEDAPASTA

Cria uma pasta onde cada subpasta é um repositório e a registra.

cria pasta
/repo <repositorio>

Localiza o repositório e mostra o estado. Se não estiver clonado, pede autorização para clonar.

leitura
/repo <repositorio> lock

Trava a sessão nesse repositório até o unlock.

trava
/repo <repositorio> unlock

Destrava a sessão.

destrava
/repo review

Valida todas as pastas registradas contra o GitHub e propõe correções.

pede aprovação
/repo review <repositorio>

A mesma validação, só em um repositório.

pede aprovação
/repo TaskManagement <repositorio>

Audita commits, PRs, reviews e atividade por usuário.

leitura

Feito para não estragar nada

A skill nunca toma uma ação destrutiva por conta própria.

  • Atualiza só com git pull --ff-only. Nada de reset --hard, clean ou push --force.
  • Não atualiza repositório com alterações não salvas ou divergente: apenas avisa.
  • Não clona, cria ou apaga nada fora das pastas que você registrou.
  • Nunca apaga um repositório clonado sem explicar o que será perdido e perguntar.
  • Não faz git push sem pedido explícito.
  • Trata nomes digitados como dado, nunca como comando de shell.
